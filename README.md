# Network Traffic Analysis Lab

## Objective

The objective of this project is to learn how to capture,
inspect, and analyze network traffic using Wireshark.

## Tools Used

- Wireshark
- Npcap
- Windows

## Lab 1: Initial Traffic Capture

A live network capture was performed on the Wi-Fi interface
using Wireshark.

The capture was allowed to run for approximately 20 seconds.

### Initial Observations

The captured traffic contained:

- TCP traffic
- TLS traffic
- QUIC traffic
- HTTPS communication over port 443
- Local and external IP addresses
